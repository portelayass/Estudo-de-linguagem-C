# Curso de C

Repositório com exercícios e exemplos desenvolvidos durante meus estudos da linguagem C.

## Conteúdos

- `01-variaveis-e-operadores`: variáveis, tipos de dados e operações matemáticas.
- `02-condicionais`: estruturas condicionais.
- `03-logica-e-switch`: conectivos lógicos, números aleatórios e `switch`.
- `04-contadores`: exercícios introdutórios de contadores.
- `05-lacos-de-repeticao`: estruturas de repetição, como `for` e `while`.
- `00-introducao`: arquivos iniciais que ainda não estão classificados.

## Como executar

É necessário ter um compilador C instalado, como o GCC ou CodeBlocks.

No terminal, entre na pasta do arquivo e compile:

```bash
gcc nome-do-arquivo.c -o programa
```

Depois execute:

- **Windows:** `programa.exe`
- **Linux/macOS:** `./programa`

Alguns exercícios podem precisar de ajustes antes de compilar, pois este repositório reúne códigos em desenvolvimento durante o aprendizado.

Organizar e registrar minha evolução nos estudos de programação em C.
